## 1. 产品定位与目标

Visual English Coach 面向英语基础较弱、需要中文辅助、希望把生活场景转化成实际表达的学习者。通过生活场景和个人记录，支持理解、开口、收藏与复习。

当前核心价值：

1. 把图片或文字描述组织成“看见什么 / 如何理解 / 可以怎样说”的英语学习内容。
2. 进入全部开放的生活场景，围绕具体任务与 AI 练习。
3. 对收藏句子提供中文、句型、词性和拓展解释，降低只会跟读、不理解的门槛。
4. 从真实尝试安排后续复习；参考表达是范例，不是唯一标准答案。
5. 用中文记录生活，生成可编辑的英语版本，确认后保存为双语日记。

当前处于**本地 Web 功能迭代及验证阶段**。学习流程已有可运行实现，尚不是完成生产安全与全平台验收的商业发布版本。

## 2. 用户与主要任务

| 用户需求 | 当前路径 | 成功结果 |
|---|---|---|
| 眼前场景不会表达 | 首页图片/文字 → 场景英语 | 获得有效英语内容并保存学习记录 |
| 想练习实际交流 | 场景地图 → 详情 → 对话任务 | 发送真实回复，看到 AI 回应及任务证据 |
| 看到句子却不理解 | 学习 → 表达句库 → 句子详解 | 看懂中文、成分、语法和词汇用法 |
| 想把学过的再次说出来 | 今天再说一次 | 明确情境后尝试，保存练习过程与下次安排 |
| 想把生活写成英语 | 英语日记 → 中文写作 → 预览 | 核对并保存对应日期的中英文 |
| 想知道自己做了什么 | 成长 / 我的 → 明细 | 查看真实记录、经验来源、日期与收藏 |

## 4. 功能需求与现行规则

### AUTH：身份与默认内容

- 本地环境在缺少有效 Supabase 配置时使用演示模式；邮箱映射演示数据拥有者。密码字段的表单校验不等于服务端密码认证。
- 云模式代码调用 Supabase 登录、注册、邮件找回与改密；是否可用依赖实际项目配置及部署。
- 应用冷启动要求本次运行内显式登录。快速体验生成新的演示身份，设计目标是不复用历史账号数据。
- 新用户没有个人学习数据时，首页显示默认概念场景；概念图片与真实照片区分说明，不虚构个人词汇、练习次数或日记。
- 本地找回/改密明确提示演示说明，不伪称发送邮件或修改密码。

### HOME / SCENE：场景学习

- 首页用于开始和继续任务，数据来自学习记录、词汇、场景统计与当前偏好。
- 图片输入经过既有图片处理链路；文字输入支持中文生活描述。
- 场景英语输出保留 `i_see / i_think / i_say` 三段；有效结果才可进入保存和后续学习。
- 支持原有简单/自然/高级表达选择、中文翻译、朗读、词汇入口、场景收藏及记录备注。
- 学习资产成功写入后失效相关缓存。未成功不得显示假收藏或假保存。
- 默认图片不标成用户照片；没有位置数据支持的热点不得称为 AI 真实图像识别结果。

### CHAT / WORLD：有任务的交流

- 地图全部开放，用户自主选择；不采用强制闯关解锁。
- 场景详情展示角色、背景及任务，具体要求由场景配置提供，不能把某个场景的 5 轮推广为全库规则。
- 用户真实发送回复、收到有效 AI 回应后才推进既有轮次和保存逻辑。
- 任务完成需引用用户本次会话已发送原句。AI 判断可能误判，轮次和任务完成不等于口语掌握。
- 默认界面聚焦聊天；表达收藏、输入帮助、原句建议与重说按需展开。
- 帮助不自动代替用户发送；重说与主输入避免互相抢占状态。
- AI 教练输出在自己的会话空间展示，不堆到首页文字场景结果下方。

### LIB / SENT：理解与积累

- 词汇详情提供实际词义、词性、搭配与例句；收录成功后才显示已收录；失败可重试。
- 点击表达句库先进入“看懂这句话”，跟读是详情内后续操作。
- 句子解析必须对应所选原句，拆解片段和重点词必须实际存在于原句；音标/词形不确定时可空。
- 缺失中文可在解析成功后写回原收藏，已有中文不自动覆盖。解析成功但回写失败时分别提示。
- 展开词汇查看用法、词形、双语搭配/例句，可朗读、进入完整词条或情境复习。
- AI 解析不是经过人工逐条审定的专业词典；界面保留辅助解析提示。

### REVIEW：复习的行为定义

- 有情境：先显示要完成的中文表达任务，再让用户尝试；可按需查看关键词与参考。
- 旧收藏缺少情境：先熟悉内容，不能让用户面对未知内容盲猜“答案”。
- 收藏句是参考表达，不把字面不同自动判为错误；文字核对不等于语义/发音认证。
- 记录输入方式、是否查看帮助、尝试文字、结果类型与可选主观费力程度。
- 跳过不计作完成；结果展示后由用户继续，避免提交后内容立即消失。
- 单账号本机队列最多 300 条，每条新历史最多保留最近 20 次；不虚构旧记录。

### DIARY：中文到双语日记

主流程：**选日期 → 中文输入 → 选表达版本 → 生成预览 → 核对/编辑 → 确认保存**。

| 要求 | 当前行为 / 验收标准 |
|---|---|
| 无学习记录也能写 | 中文自由输入，最多 4000 字符 |
| 三种版本 | 自然表达、简单英语、润色表达；润色改善措辞与衔接，不要求补造经历 |
| 源文变动 | 提示“原文已修改，需要重新翻译”；旧英文不能保存为新源文译文 |
| 保存控制 | 生成不直接入日记；保存成功才显示已保存；失败保留输入与预览 |
| 日期 | 默认今天，完整月历补写过去，未来不可选；已有日记打点；日记日期和创建时间分开 |
| 草稿 | 按账号/日期/周范围保留在此设备，三版本候选对应各自源文；不是跨设备同步 |
| 编辑 | 英文可修改；手动修改后清除可能已失效的自动拓展 |
| 阅读 | 英文默认，可显示中文对照，支持朗读与停止；旧日记无中文时如实提示 |
| 表达学习 | 最多 3 条正文内的表达，默认折叠，主动收藏才写入句库；可进入详解 |
| 学习记录 | 可选带入当天真实练习内容，不把练习冒充真实生活经历 |
| 周记 | 优先汇总选中周已保存每日日记，否则明确回退到真实学习记录；先预览后确认 |
| 兼容与删除 | 原英文 `content` 保留；更新按已有日记复用记录；删除需确认；没有新增日期唯一约束或自动清理历史重复项 |

AI 翻译及周记仍可能误译、遗漏或误推事件先后，需用户核对。提示词约束不等于事实绝对正确。

### GROWTH / PROFILE：真实记录与控制

- 成长等级根据 XP 计算，只表示产品内累计行为。勋章与称号不作为英语水平认证。
- 个人指标打开对应明细、学习日历和来源，不全部跳到重复的学习/成长首页。
- 身份与偏好可管理，头像保持纯头像风格；系统相册入口已实现，文件读取/上传仍需独立验收。
- 默认朗读速度、每日场景目标、常用场景接入真实使用；偏好和昵称/称号按账号本机保存。
- 设置展示本地服务状态，数据清理具有确认流程；不把清理与退出登录混为一项。

## 5. 数据与奖励规则

数据库保存学习记录、词汇、句子、场景、日记、XP 与活动/地图进度；本机保存复习、日记草稿及部分个人偏好。

当前本地奖励基准：每日签到 10、场景分析 20、对话事件 30、跟读 25、翻译事件 5、学习场景事件 10 XP。签到连续每满 7 天额外 50 XP。以上是服务端可接受事件规则，不意味着每个页面按钮都会发奖。

连续签到由签到事件维护；奖励按来源、账号及奖励日期去重。活动计数与 XP 写入的并发死锁已修复并回归。未自动补写真实用户历史丢失 XP。

## 6. 体验与质量要求

- 显示加载、空内容、失败、重试、保存中和已保存的区别。
- 失败不清空用户草稿；迟到响应不能覆盖新输入、另一日期或另一个账号的视图。
- 点击/拖拽区分，手势不阻碍纵向滚动；关闭恢复原场景，停止音频与进行中动画。
- 375/390/430px 下主要流程无横向溢出；这不替代真机键盘、横屏与辅助技术验收。
- 按压与弹簧动效沿用已有实现，支持减少动态效果；60fps 是优化目标，尚无完整性能实测认证。
- API 密钥只放服务端配置，不写入公开前端或文档。当前本地请求头身份不是生产权限体系。

4. 访客完整隔离、找回密码邮件、旧 `/map`、`/dialogue` 等低频路径补测。
