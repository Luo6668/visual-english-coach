# R1 情境与旧收藏兼容

## 需求与目标
复习前明确要表达什么。收藏句是参考说法，不能作为唯一答案；缺少情境时不隐藏内容让用户猜。

## 开发
- `src/lib/learning-loop/review-practice.ts` 的 `reviewPrompt`：优先使用真实中文意图；不同的原始表达作为改写线索；两者均缺失时进入熟悉模式，直接展示收藏原句。
- `ReviewPracticeCard` 按真实来源显示情境；没有虚构店员台词，没有伪造 AI 图像结果。
- 熟悉模式可主动补充自己的情境。保存不改变历史、次数和复习计划；本轮已经看到参考，仍记熟悉练习，下次再按新情境练习。
- 全部列表显示每条的情境/原句，不再显示一串难以区分的相同场景名。

## 测试与验收标准
有情境可直接作答；无情境看得到参考；旧数据可读；补情境后旧字段、日期和次数保留；英文参考本身不能当作隐藏英文的情境。

## 实测结果 · 通过
- 独立 QA 账号的两条旧收藏没有 cue，均直接显示原句与听参考入口，没有猜句子流程。
- 页面内补充两条真实含义后，下次进入显示对应情境；本轮仍记录 familiarized。
- 冷刷新后从登录开始，情境与历史保留；旧记录不自动补造历史。
- 纯规则测试覆盖缺 cue、不同原句、cue 等同参考、补情境不改计划。
