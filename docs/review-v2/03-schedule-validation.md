# R3 复习安排与整体验收

## 需求与目标
不把查看帮助当失败，不把点击自评当掌握。保存后看得到本次结果和下次安排，由用户进入下一条。

## 开发
- 新路径使用 `applyReviewAttempt` / `recordReviewAttempt`；移除旧“hinted / independent”按钮驱动的规则函数。旧字段仅兼容保留，不清零历史。
- 默认完成尝试后约 1 天再练；“稍后再练”约 30 分钟。连续无提示且自感顺畅时逐步 1/3/7/14 天，属于复习计划，不是能力分。
- 跳过不增加尝试次数、不改变到期时间，单独记录跳过行为；没有输入的跳过记 method=none。
- 保存前固定当前条目，避免 store 发布新队列导致结果卡瞬间被下一条替换。用户点继续下一条后再切换。
- 最近 20 条新练习记录按条目保存，可展开最近 3 条；累积次数不因历史截断而减少。不虚构旧版本未保存的表达文本。
- 新字段为可选，沿用既有账号分区和存储版本；写入失败不替换可见快照，不涉及数据库结构、登录或 XP。

## 测试与验收标准
旧队列兼容；重复保存幂等；跳过不改计划；帮助不清历史；保存卡保留至主动下一条；刷新持久化；375/390/430px 正常；错误可恢复。

- `pnpm typecheck`：通过。
- `pnpm test:learning`：46/46，通过；新增复习规则及替换旧错误定义的用例均通过。
- 复习独立入口：`pnpm test:review` / `pnpm test:learning:review`，覆盖 M4。
- 本轮 TS/TSX 文件定向 oxlint 与 `git diff --check`：通过。不声明全库 lint 通过。
- 实际浏览器：熟悉→补情境→不同表达→可选 AI→保存；关键词辅助；提交后看参考；存储失败重试；麦克风拒绝；跳过；到期/全部切换；刷新后重新登录均通过。
- 跳过前后次数、到期日期完全一致；熟悉练习“稍后再练”记录间隔为 30 分钟。
- 作答页与提交页在 375/390/430px CSS 视口分别验证 innerWidth=scrollWidth，截图在 evidence/。
- 保存成功停在结果卡，继续下一条才切换，页面操作验证通过。

## 未覆盖与限制
- 小屏为 Chromium CSS 视口，不替代真实手机触摸、软键盘与原生 iOS/Android 验收。
- ASR 权限错误恢复已测；本轮未做真实麦克风口音、噪声或音质验收。
- 可选 AI 建议使用现有本地接口，本轮不部署云函数；建议可能有误。
- 复习记录保存在此设备按账号隔离，暂不支持云同步。
