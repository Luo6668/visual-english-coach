## 恢复与启动

1. 从本次 Git 标签或对应提交检出源码，安装依赖 `pnpm install --frozen-lockfile`。
2. 按根目录 README 从 `.env.example`、`mysql/.env.example`、`supabase/.env.example` 建立本机私有配置；密钥不在仓库中。
3. 新数据库运行 `pnpm mysql:init`；已有数据库运行 `pnpm mysql:migrate:diary`，只添加日记可空字段，不改写旧正文。
4. 本地语音模型需另行 `pnpm speech:setup`，不随 Git 上传。
5. 启动 `pnpm dev:local`，按终端地址访问；每次冷启动从登录开始。
6. 本次源码保存不包含 MySQL 用户实际数据、私人日记、录音或环境配置备份；恢复个人数据应沿用原数据库或用户自有数据库备份。
