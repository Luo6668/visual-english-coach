# C1 表达收藏

## 需求与目标
AI 回复保留正文、朗读、慢速和中文；不自动铺“值得记住的表达”卡。用户主动收藏时才选择原句，减少读完每句后的操作负担。

## 开发
- 独立组件：`src/components/learning-loop/message-expression-save.tsx`。
- 候选提取：`src/lib/learning-loop/presentation.ts`；保留英文原句、价格和短实用句，排除中文解释、重复句与简单应答。
- 接入 AI 教练与场景对话，复用真实表达本 API 与按账号存储的复习队列。收藏后仅一行成功提示，可再选择加入复习。
- 查重、失败、重试分别管理；账号变化或组件离开后不向新账号写入旧结果。

## 测试与验收标准
默认无候选卡；点击才展开；保存写入真实表达本；同句不重复新增；加入复习为可选；保存失败不误用 AI 对话重试。

## 实测结果 · 通过
- 独立 QA 账号收藏两条真实 AI 回复，表达本均可读取；选其中一句再次保存，记录数未增加。
- 可选加入复习后队列读取成功，再次展开能识别已加入状态。
- 注入收藏接口 503 后仅显示局部错误，输入草稿保留；恢复接口后重试成功。
- C1 候选提取 4 项规则测试通过，包含中英混排、价格、重复句和短实用句。
