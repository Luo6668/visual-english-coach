# C2 输入区帮助

## 需求与目标
把帮助收进输入区上方的“提示”入口；用户需要时再选关键词、参考回答或简化上一句。避免帮助卡混入对话正文。

## 开发
- `conversation-help-card.tsx` 负责轻入口与有高度上限的内联面板；不再叠加一个 Modal。
- `learning-companion.tsx` 负责请求与会话状态，关闭、发送、离开会话时使旧请求失效。
- 帮助结果不会自动发送，不增加对话轮次，不清空草稿；录音和单句重说期间隐藏。
- Escape 优先关闭帮助并恢复焦点，保留 AI 对话层；入口可键盘操作。

## 测试与验收标准
默认只有提示入口；真实请求生效；结果不会占据主消息列表；关闭或发送后迟到结果不能重新打开；失败可局部重试且保留草稿。

## 实测结果 · 通过
- 真实关键词请求返回，原输入 `I has a reservation.` 保留；发送后工具自动收起。
- 注入 503，帮助区显示错误，`Hot, please.` 草稿保留；恢复后重试得到真实提示。
- 挂起请求、手动关闭、再释放请求，面板保持关闭。
- 真正按键 Escape 只关闭提示，对话层和主输入仍在；焦点回到提示入口。
