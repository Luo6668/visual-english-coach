# C3 原句旁建议

## 需求与目标
反馈跟随对应用户原句；不再在列表末尾自动叠放完整练习卡。默认专心对话，需要时再查看解释与重说。

## 开发
- `inline-expression-feedback.tsx` 显示轻量建议；`learning-companion.tsx` 按消息 ID 保留反馈与实际提示使用情况。
- `none` 自动反馈静默；用户主动请求后若无修改，仅一行“这句无需修改”。
- `natural` 默认仅一行入口；`correction` 默认短标签与建议句。展开复用真实朗读、核对、保存、重说组件。
- 同时最多一个详情区；重说期间与主输入互斥，收起恢复。查看旧消息时停止强制跟随到底部。

## 测试与验收标准
正确句不弹成功卡；建议在正确原句下；只展开一个重说区；核对、保存、朗读入口保留；异步结果不得跨会话污染。

## 实测结果 · 通过
- 实际发送错误句，建议贴在原句下，默认无重说大卡；展开后可核对正确表达，收起恢复主输入。
- `I have a reservation under Alex.` 自动不产生额外反馈卡；聊天模式主动查看后只显示“这句无需修改”。
- 连续两条错误句分别展开，页面始终只有一个练这句入口与详情区，旧建议没有移到新消息下。
- C3 静默与反馈类型区分规则测试通过。小屏实测见 [375px](evidence/coach-375.png)、[430px](evidence/coach-430.png)。
