# M2 · 对话内帮助

## 需求与目标
在 AI 教练与场景对话内获得关键词、范例或更简单的对方说法，不必跳转、不自动替用户回答。

## 功能设计与开发
- 独立 LearningCompanion 组件和 assistant.ts 接口封装。
- 三个显式操作：关键词提示、参考回答、对方说简单些。上下文使用最近一条 AI 消息、用户当前草稿及当前场景目标。
- 提示展开后保留当前草稿；参考回答只能用户主动复制到输入框，禁止自动发送。
- 同一面板只允许一个请求，取消/退出可忽略迟到结果，超时与异常可重试。
- 查看范例后记录“有提示”，不能归为独立说出。

## 测试
帮助请求参数、长度与动作白名单；空上下文、超时、无效 JSON；快速重复点击不重复提交；关闭/卸载不更新旧状态。

## 验收标准
两类对话均可使用；点击提示不增加消息/XP；输入不丢失；失败有重试；提示由真实模型生成，不能用预置成功结果顶替。

## 实测结果
开发完成，本地 Web 验收通过。

- 实现：`assistant.ts`、独立 `conversation-help-card.tsx`；`learning-companion.tsx` 仅做请求协调；本地/云端共用 `learning-assist.mjs` 契约。
- 独立测试：`pnpm test:learning:help`，6 项通过。
- 新增“帮我练会 / 陪我聊聊”：前者自动展示结构化建议，后者只在主动点击后展示。两个模式共用 `coach-system.mjs`，避免聊天正文和学习面板重复批改。
- 实际接口验证关键词、完整参考回答、简化对方原句均返回有效内容；非法动作拒绝，无 XP/消息写入。
- 浏览器注入 503：Hot, please. 草稿和 3 项目标证据保留；恢复服务后点击重试，提示正常出现，草稿未自动发送。
- 畅聊模式浏览器未自动出现结构化批改；主动点击可获得反馈。对话模式提示词调整后，真实接口对错误句直接接续预订情景，而非在正文重复纠正。
- 收起过程中忽略迟到响应；重新展开后，可主动点击“看看这句建议”重新获取未完成的反馈。
- 限制：云端入口已提供源码并复用已测试契约，本次未部署 Supabase 云函数。
