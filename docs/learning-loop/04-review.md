# M4 · 基于真实表现的复习

> 最新复习逻辑与验收以 [Review v2](../review-v2/00-progress.md) 为准。以下为 v1 历史记录，旧“揭示答案 / 独立自评”流程已替换。

## 需求与目标
收藏的真实句子和用户主动收录的纠正表达可进入复习。空账号不产生假历史；复习安排受实际行为影响，可从表达本打开独立页面。

## 功能设计与开发
- model.ts 纯函数决定到期、去重与间隔；store.ts 按当前用户 ID 保存，web localStorage / native SQLite KV，明确当前设备范围。
- 收藏句子需主动加入复习；记录原句、目标句、解释、场景、来源、创建/到期时间、练习次数与最近方式。
- 复习先显示场景和已保存的中文提示（旧条目可用不同的原句作为改写线索），用户尝试后可揭示答案并朗读。
- “还需提示”：短间隔；“本次独立说出”：延长到明天/3天/7天。展示答案后禁选独立；明确是用户自评而非专业测评。
- 可移除并持久化；失败保留当前卡；列表与计数实时更新；到期/全部筛选可查看计划。
- 不因复习按钮点击额外发 XP，避免重复刷分。

## 测试
重复句合并、异账号隔离、到期边界、UTC 时间与本地展示、揭示答案限制、写入失败、并发更新、损坏存储显式报错、不覆盖未知数据。

## 验收标准
新账号空态；真实表达加入后可见；复习后到期时间改变；刷新仍保留；其他账号不可见；写入失败不丢旧队列；375/390/430px 可操作。

## 实测结果
开发完成，本地 Web 验收通过；原生 SQLite 路径仍待设备验收。

- 实现：`model.ts`、可注入存储的 `repository.ts`、`store.ts`、独立路由 `review.tsx`，从表达本入口进入。
- 独立测试：`pnpm test:learning:review`，12 项通过。
- 账号 A 保存 2 条，账号 B 显示 0 条；重新登录 A、浏览器冷重载后登录 A 均保留 2 条。
- 浏览器揭示答案后“独立说出”禁用；有提示排到 10 分钟后，独立自评排到次日；typed / voice 方式实际写入。
- 注入配额写入失败：草稿和原 attempts=0 保留，无虚假成功；恢复后可正常写入。
- 真实 QA 表达本句子可主动加入复习，带入中文提示；重复加入不新增；移除复习项后，数据库原收藏仍存在。
- 375 / 390 / 430px 实测根 scrollWidth 与 viewport 相等，操作控件均位于水平边界内；系统减少动态效果媒体查询已验证启用。
- 旧条目缺中文提示时明确提示，不虚构译文；有新提示的重复表达仅补齐提示，不清零真实次数或修改到期计划。
- 当前数据为此设备按账号隔离保存，不宣称跨设备云同步；独立说出为用户自评，不是专业测评。
