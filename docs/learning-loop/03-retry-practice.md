# M3 · 纠正后重说

## 需求与目标
对用户真实发送的英语给出一项最值得改善的反馈，区分语法错误和自然表达建议；听建议、自己重说，再决定是否收进复习。

## 功能设计与开发
- AI 返回 correction / natural / none 三类结果；原句必须和发送内容一致，空建议/相同建议不得显示假纠错。
- feedback 卡显示原句、建议和简短说明，提供原有 TTS 朗读与“练这句”。
- 重说通过原有麦克风识别到输入框，或用户手动输入，再点击“检查这次表达”；不自动发送进主对话。
- 本轮使用规范化文字匹配，仅描述是否与练习句一致；支持手动结束，不生成发音分数。
- 标注 typed/voice 来源与是否看过提示；语音识别失败不提交练习结果。
- 收录复习由用户主动操作；重复点击、重复句子合并，不产生重复条目。

## 测试
同义表达不判语法错（仅给未匹配提示）；大小写/标点规范化；空输入拒绝；原句漂移/无效反馈过滤；写入失败不显示成功；旧请求覆盖保护。

## 验收标准
真实错误句可得到反馈；正确句允许“无需修改”；可朗读、录音/输入重说、检查、保存；匹配不等于发音得分；保存后在复习页面可见。

## 实测结果
开发完成，本地 Web 验收通过；真人设备麦克风仍待实机验收。

- 实现：独立 `expression-practice-card.tsx` 反馈/重说组件、`practice-input.tsx` 的录音生命周期、`model.ts` 的文字匹配规则。
- 独立测试：`pnpm test:learning:retry`，6 项通过。
- 真实模型区分 none / natural / correction；I has a reservation. 得到 I have a reservation.，并产生“我有预订”的复习提示。
- 浏览器输入重说核对通过；进入单句练习后隐藏主对话输入区，避免两个输入框与两个麦克风相互干扰。
- 权限拒绝模拟：出现可理解错误，保留文字替代路径，不产生练习成功记录。
- 合成语音回放端到端：Kokoro 生成测试英语，经浏览器 MediaRecorder 实际录制、WAV 转换和真实 Whisper 识别，返回 Could I have a medium latte to go please?；记录来源为 voice。
- `pnpm smoke:speech`：英语/普通话/混合 TTS 与 Whisper 均通过；浏览器朗读 currentTime>0、readyState>=2、paused=false。
- 文字相同只说明识别文本一致，不声称发音、语调、流利度达到某个分数。


组件拆分后再次验收：单句收录失败仅在表达卡内显示，不能出现错误的 AI 重试按钮；保留重说输入，重新点击收录可正常保存。
