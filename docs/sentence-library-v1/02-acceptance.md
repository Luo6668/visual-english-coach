# 表达句库详解 · 实际验收

## 前后区别

以前：点击表达句库直接跟读，难以先理解。
现在：进入“看懂这句话”独立页，先看原句中文和解释，再看句型成分、语法、重点词在本句的词性与含义；词卡展开后有词形、常用搭配和双语例句，仍可听发音、打开完整词条、加入情境复习或跟读原句。

## 自动化与约束

- test:sentences 9/9：原句一致、输入边界、词/片段边界、中文/词性/例句完整性、允许空音标与词形、提示注入边界。
- test:learning 46/46；typecheck、全库 lint、Web 导出通过。
- 账号分区缓存；不存在或非当前账号收藏不给旧内容；请求有代次/卸载保护。云端要求认证，使用共享结构验证。本轮浏览器未伪造他人收藏测试，不将代码保护等同于全面渗透测试。
- 解析不使用固定演示结果，已有中文不自动覆盖；中文写入失败与解析失败分开呈现。
- 中文辅助解析由 AI 生成，不能保证每条语法事实绝对正确；真实麦克风、原生平台及云端部署不在本轮通过范围。
