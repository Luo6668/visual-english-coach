# 需求文档

## 1. 应用概述

### 1.1 应用名称
Visual English Coach

### 1.2 应用描述
一款把现实世界实时转换成英语思维的AI学习助手。帮助英语基础较弱、不敢开口说英语的用户，通过拍照识别或手动输入场景，将眼前看到的场景、物体和事情转化成英语思维模式表达，并提供AI场景对话练习、专业影子跟读训练、发音纠错、单词解释和自动记忆功能。用户可记录学习过程，生成英语日记和周记，通过游戏化成长系统长期积累英语表达能力。

### 1.3 产品定位
把现实世界实时转换成英语思维的AI学习助手。不是普通翻译工具，不是普通英语学习App，而是训练英语思维的AI助手。

### 1.4 设计风格
- 更有活力的配色方案，适合英语学习应用
- iOS风格设计
- 渐变色应用于hero区域和关键视觉元素
- 主色调：活力蓝（#4A90E2）到深蓝（#2E5C8A）渐变
- 辅助色：明亮黄（#FFD60A）、清新绿（#34C759）
- 背景色：纸白色（#F7F7F5）
- 文字色：深色（#1C1C1E）
- 卡片阴影：柔和多层阴影效果
- 圆角：统一使用16px圆角
- 间距：采用8px基础网格系统
- 微动画：卡片hover效果、页面切换过渡动画、加载动画
- 界面加入实景图片展示，图片区域采用圆角和渐变蒙版处理
- 空状态和加载状态采用插画风格视觉

## 2. 用户与使用场景

### 2.1 目标用户
- 英语基础较弱的学习者
- 不敢开口说英语的用户
- 希望通过日常场景练习英语表达的用户
- 希望训练英语思维而非翻译思维的用户

### 2.2 核心使用场景
- 用户在日常生活中看到某个场景或物体，想用英语思维表达
- 用户通过拍照识别场景，获取三步场景英语表达（看场景/学表达/开口说）
- 用户手动输入场景描述，获取英语思维表达
- 用户输入中文描述，获取对应的英语思维表达
- 用户进入AI场景对话模式，与AI角色进行真实场景对话练习
- 用户使用Shadowing跟读模式进行专业影子跟读训练
- 用户学习生成的英文表达，包括发音、单词解释、搭配和例句
- 用户查看自动生成的今日高频词，系统辅助记忆
- 用户查看AI英语地图，了解场景覆盖情况和学习建议
- 用户查看学习记录、英语日记和周记，回顾学习过程
- 用户通过英语世界地图查看场景解锁情况和学习进度
- 用户通过场景地图进行系统化场景对话练习，解锁不同场景关卡

### 3.2 注册/登录页面

#### 3.2.1 注册功能
- 用户输入邮箱
- 用户设置密码
- 完成注册

#### 3.2.2 登录功能
- 用户输入邮箱
- 用户输入密码
- 完成登录

### 3.3 首页

#### 3.3.1 UI优化要点
- Hero区域采用蓝色渐变背景（#4A90E2到#2E5C8A）
- Hero区域包含欢迎文案和学习统计数据可视化
- 学习统计数据采用卡片形式展示，包含图标、数字和进度条
- 功能入口卡片采用白色背景、16px圆角、柔和阴影
- 功能入口卡片包含图标、标题和简短描述
- 卡片间距统一为16px
- 学习时间线采用时间轴样式，每条记录带缩略图和卡片样式

#### 3.3.2 拍照识别入口
- 点击进入场景识别页面，默认打开相机

#### 3.3.3 手动输入入口
- 点击进入场景识别页面，默认显示输入框

#### 3.3.4 中文转英文入口
- 点击进入场景识别页面，默认显示中文输入框

#### 3.3.5 每日英语学习小贴士
- 展示每日一句英文学习技巧或励志短句
- 包含英文内容和中文解释
- 显示当前日期（如2026年6月19日）
- 采用精美横向卡片样式，颜色和设计与整体浅蓝风格一致

#### 3.3.6 推荐场景卡片
- 横向滚动展示推荐场景列表
- 每张卡片包含场景图标、场景名称和一个示例英文短句
- 推荐场景包括：咖啡馆、餐厅、办公室等常见生活英语场景
- 点击卡片后进入该场景的AI英语思维模式页面（thinking-mode）

#### 3.3.7 学习时间线
- 按时间分组展示学习记录（今天/昨天/本周）
- 每条记录显示场景缩略图和简短描述
- 点击记录进入对应的学习记录详情页面

### 3.4 场景识别页面

#### 3.4.1 拍照功能
- 调用系统相机拍照
- 拍照后上传图片，调用LLM API进行场景识别
- 生成英语思维模式表达
- 跳转至AI英语思维模式页面

#### 3.4.2 手动输入功能
- 用户在输入框中输入场景或物体描述
- 提交后调用LLM API生成英语思维模式表达
- 跳转至AI英语思维模式页面

#### 3.4.3 中文转英文功能
- 用户在输入框中输入中文描述
- 提交后调用LLM API生成对应的英语思维模式表达
- 跳转至AI英语思维模式页面

### 3.5 AI英语思维模式页面（Thinking Mode）

#### 3.5.1 UI优化要点
- 场景图片采用16px圆角，底部添加渐变蒙版
- 三栏卡片采用白色背景、16px圆角、多层柔和阴影
- 每栏卡片包含图标、标题和英文内容
- 卡片间距为12px
- 难度切换按钮采用胶囊样式，选中状态带渐变背景
- 播放按钮、收藏按钮采用圆形图标按钮样式
- 单词可点击区域带下划线和颜色标识
- 页面切换时带淡入淡出过渡动画
- 卡片加载时带从下到上的滑入动画

#### 3.5.2 场景图片展示
- 页面顶部展示识别的场景图片
- 图片占据页面上半部分，下方为三步场景英语表达

#### 3.5.3 三步场景英语展示
- 看场景（See）：用一句简短、客观的英语描述眼前场景，例如「The coffee shop is busy.」
- 学表达（Learn）：给出该场景最常用、最容易立即使用的表达，例如「I'd like a latte, please.」
- 开口说（Speak）：给出更自然、完整且可以直接对别人说的口语，例如「Could I get a medium oat-milk latte to go, please?」
- 不强制使用 I see、I think 或 I'd say 开头，朗读内容只包含真正需要学习的英文句子

#### 3.5.4 难度切换
- 提供简单、自然、高级三种难度选项
- 切换难度后，调用LLM API重新生成三步场景表达内容

#### 3.5.5 整句发音播放
- 点击播放按钮，播放三步场景英文表达的发音

#### 3.5.6 单词详情查看
- 点击句子中的单词，跳转至单词详情页面

#### 3.5.7 进入AI场景对话练习
- 点击按钮，进入AI场景对话练习页面

#### 3.5.8 进入Shadowing跟读模式
- 点击按钮，进入Shadowing跟读模式页面

#### 3.5.9 翻译成中文功能
- 三步英文卡片（看场景/学表达/开口说）各提供「翻译成中文」按钮
- 点击按钮后调用DeepSeek翻译API，将对应英文内容翻译成中文
- 译文以卡片形式展示在英文内容下方
- 再次点击按钮可折叠隐藏译文

#### 3.5.10 页面状态保持
- 使用hasGenerated标记确保AI分析只执行一次
- 从子页面（单词详情/AI对话/Shadowing）返回时，分析结果和译文状态完整保留
- 不会重新触发AI分析

#### 3.5.11 收藏功能
- 用户可收藏当前句子和场景

### 3.6 AI场景对话练习页面

#### 3.6.1 AI角色对话
- AI扮演场景中的角色（服务员、店员等）
- AI主动发起对话，引导用户进行对话练习
- 例如：拍照咖啡店 → AI扮演服务员 → 「Hi, what can I get for you today?」

#### 3.6.2 用户输入回复
- 用户在输入框中输入英文回复
- 提交后AI接收用户回复

#### 3.6.3 AI判断与建议
- AI判断用户回复是否自然
- 给出更地道的表达建议
- 例如：用户输入「I want coffee」，AI建议「更自然的说法是：I'd like a coffee, please.」

#### 3.6.4 持续对话
- 对话可以持续进行，模拟真实场景
- AI根据用户回复继续对话

### 3.7 Shadowing跟读模式页面

#### 3.7.1 AI播放句子
- AI播放一句英文，带明显停顿
- 用户准备跟读

#### 3.7.2 用户跟读录音
- 用户立即跟读模仿
- 系统录制用户发音

#### 3.7.3 评分与详细反馈
- 系统给出评分和详细反馈
- 反馈内容包括：
  + 发音准确率（如85分）
  + 重音位置是否正确
  + 哪个单词发音偏弱
  + 例如：「发音 85分，sitting发音偏弱，coffee重音错误」

#### 3.7.4 重新跟读
- 用户可重新跟读，直到满意为止

### 3.8 单词详情页面

#### 3.8.1 单词发音
- 点击播放按钮，播放单词发音

#### 3.8.2 音标
- 展示单词的音标

#### 3.8.3 中文意思
- 展示单词的中文释义

#### 3.8.4 词性
- 展示单词的词性（如名词、动词、形容词等）

#### 3.8.5 常见短语和搭配
- 展示该单词的常见短语和搭配

#### 3.8.6 场景例句
- 展示包含该单词的场景例句

#### 3.8.7 收藏功能
- 用户可收藏当前单词

### 3.9 学习记录/英语日记页面

#### 3.9.1 学习记录列表
- 按时间倒序展示用户的学习记录
- 每条记录包含：
  + 学习日期
  + 场景图片或输入内容
  + 场景名称
  + 场景英语表达（看场景/学表达/开口说）
  + 重点单词
  + 是否进行AI对话练习
  + 是否进行Shadowing跟读
  + 是否收藏
- 点击记录进入记录详情页面

#### 3.9.2 记录详情
- 展示原始图片或输入文本
- 展示场景识别结果
- 展示三种难度的英语思维表达
- 提供整句发音播放
- 提供单词详情查看
- 展示AI对话练习记录
- 展示Shadowing跟读结果和AI反馈
- 用户可添加或编辑个人备注

#### 3.9.3 英语日记生成
- 用户选择当天的多条学习记录
- AI自动生成一篇第一视角英文日记
- 日记内容包括：
  + 今天看到的场景
  + 今天发生的事情
  + 今天学到的表达
  + 用户的感受
- 生成的日记可保存和分享

#### 3.9.4 Weekly Story（周记）生成
- AI自动汇总本周学习内容，生成一篇英文周记
- 周记内容包括：
  + 本周访问的场景
  + 本周练习的英语表达
  + 本周学习的新单词数量
  + 本周的学习成就
- 例如：「This week I visited several coffee shops. I practiced describing daily life in English. I learned 42 new words.」
- 生成的周记可保存和分享

#### 3.9.5 用户备注功能
- 用户可为每条学习记录添加中文备注
- 备注内容存储在后端

### 3.10 我的表达本页面

#### 3.10.1 场景本
- 展示用户去过/拍过的所有场景
- 点击场景进入对应的学习记录详情页面

#### 3.10.2 句子本
- 展示用户收藏的所有英文表达
- 点击句子进入对应的表达详情页面

#### 3.10.3 单词本
- 展示用户点击学习过的所有单词
- 点击单词进入对应的单词详情页面

#### 3.10.4 今日高频词
- 系统自动统计今日学习中出现2次以上的单词
- 自动生成「今日高频词」列表
- AI辅助记忆，无需用户手动操作
- 点击单词进入对应的单词详情页面

### 3.11 AI英语地图页面

#### 3.11.1 已练习场景展示
- 用emoji+场景名展示已练习的场景及次数
- 例如：咖啡店12次、地铁6次、超市8次

#### 3.11.2 未练习场景标注
- 标注从未练习过的场景
- 例如：医院0次、机场0次、银行0次

#### 3.11.3 AI学习建议
- AI根据用户场景覆盖情况给出学习建议
- 例如：「你的旅游英语不足，建议练习机场场景」

### 3.12 英语世界地图页面

#### 3.12.1 顶部英雄区
- 紧凑展示用户当前等级信息
- 包含等级徽章、等级名称（如Lv.3 进阶学员 / Advanced Learner）
- 展示当前XP/升级所需XP（如450/600）
- 展示升级进度条，带动画效果
- 展示连续学习天数（如连续学习7天）
- 采用渐变背景（#4A90E2到#2E5C8A）

#### 3.12.2 场景地图区
- 展示多个学习场景节点，包括：
  + Coffee Shop / 咖啡馆
  + Airport / 机场
  + Restaurant / 餐厅
  + Office / 办公室
  + Park / 公园
  + Supermarket / 超市
  + Subway / 地铁
  + Hospital / 医院
  + Library / 图书馆
  + Gym / 健身房
- 场景节点采用卡片形式展示
- 卡片圆角28px，渐变背景，毛玻璃质感
- 已解锁场景高亮显示（绿色/彩色），未解锁场景灰色半透明
- 地图风格参考游戏解锁地图或Duolingo关卡地图，视觉层次丰富

#### 3.12.3 场景卡片详情
- 每个场景卡片显示：
  + 场景名（中英双语，如Coffee Shop / 咖啡馆）
  + 场景图标或图片
  + 掌握度进度条
  + 已学表达数量（如已学15个表达）
- 点击场景卡片进入对应场景的学习记录详情页面

#### 3.12.4 场景解锁机制
- 用户学习某个场景后，该场景自动解锁
- 已解锁场景高亮显示，未解锁场景灰色半透明
- 解锁后场景卡片显示掌握度进度条和已学表达数量

### 3.13 场景地图页面

- 以地图/冒险地图风格展示多个学习场景
- 每个场景是一个关卡节点，直观展示学习路径和进度
- 场景节点状态包括：已完成、进行中、未解锁

## 4. 业务规则与逻辑

### 4.1 场景识别与英语思维生成
- 用户拍照、输入场景或输入中文描述后，调用LLM API进行场景识别和内容分析
- 拍照场景使用多模态视觉模型进行图片识别，准确识别场景内容
- 根据识别结果调用LLM API生成三步场景英语表达：
  + 看场景（See）：简短描述眼前的场景
  + 学表达（Learn）：学习最常用的场景表达
  + 开口说（Speak）：练习更完整自然的实际口语
- 根据用户选择的难度（简单/自然/高级），调用LLM API生成对应难度的表达内容
- 每条表达都是基于场景真实生成，而非模板替换

### 4.2 每日英语学习小贴士
- 系统每日自动生成一句英文学习技巧或励志短句
- 包含英文内容和中文解释
- 显示当前日期

### 4.3 推荐场景卡片
- 系统展示常见生活英语场景列表（咖啡馆、餐厅、办公室等）
- 每个场景包含场景图标、场景名称和一个示例英文短句
- 用户点击推荐场景卡片后，系统调用LLM API生成该场景的英语思维模式表达
- 跳转至AI英语思维模式页面（thinking-mode）

### 4.4 AI场景对话练习
- 用户进入AI场景对话练习页面后，AI扮演场景中的角色
- AI主动发起对话，引导用户进行对话练习
- 用户输入英文回复后，AI判断回复是否自然
- AI给出更地道的表达建议
- 对话可以持续进行，模拟真实场景

### 4.5 Shadowing跟读模式
- AI播放一句英文，带明显停顿
- 用户立即跟读模仿
- 系统录制用户发音并分析
- 系统给出评分和详细反馈：
  + 发音准确率
  + 重音位置是否正确
  + 哪个单词发音偏弱
- 用户可重新跟读，直到满意为止

### 4.6 发音与跟读
- 整句发音：播放完整句子的标准发音
- 单词发音：播放单个单词的标准发音

### 4.7 翻译功能
- 用户点击三栏英文卡片的「翻译成中文」按钮后，调用DeepSeek翻译API
- 译文以卡片形式展示在对应英文内容下方
- 再次点击按钮可折叠隐藏译文
- 译文状态在页面切换后保持不变

### 4.8 页面状态管理
- thinking-mode页面使用hasGenerated标记记录AI分析是否已执行
- 首次进入页面时执行AI分析，hasGenerated设为true
- 从子页面返回时，检查hasGenerated标记，若为true则不重新执行AI分析
- 分析结果、译文展开/折叠状态在页面切换后完整保留

### 4.9 生词自动记忆与今日高频词
- 系统自动统计今日学习中出现2次以上的单词
- 自动生成「今日高频词」列表
- AI辅助记忆，无需用户手动操作

### 4.10 学习记录自动生成
- 用户每次拍照、输入场景或输入中文描述后，系统自动生成一条学习记录
- 学习记录包含：
  + 日期时间
  + 场景图片/手动输入内容
  + AI识别出的场景
  + 场景英语表达（看场景/学表达/开口说）
  + 学过的单词
  + 收藏的句子
  + AI对话练习记录
  + Shadowing跟读评分
  + 用户自己的中文备注
- 学习记录存储在后端

### 4.11 英语日记与周记生成
- 用户选择当天的多条学习记录，AI生成一篇第一视角英文日记
- 日记内容整合今天的场景、事情、表达和感受
- AI自动汇总本周学习内容，生成一篇英文周记
- 周记内容包括本周访问的场景、练习的英语表达、学习的新单词数量、学习成就
- 生成的日记和周记可保存和分享

### 4.12 收藏与表达本
- 用户收藏的句子、单词和场景存储在后端
- 场景本记录用户去过/拍过的所有场景
- 句子本记录用户收藏的所有英文表达
- 单词本记录用户点击学习过的所有单词
- 今日高频词自动生成，展示今日学习中出现2次以上的单词
- 表达本内容支持取消收藏

### 4.13 AI英语地图
- 系统自动统计用户已练习的场景及次数
- 用emoji+场景名展示已练习的场景
- 标注从未练习过的场景
- AI根据用户场景覆盖情况给出学习建议

### 4.14 英语世界地图与场景解锁

#### 4.14.1 场景解锁规则
- 用户学习某个场景后（拍照识别、手动输入或中文转英文），该场景自动解锁
- 已解锁场景高亮显示（绿色/彩色），未解锁场景灰色半透明
- 解锁后场景卡片显示掌握度进度条和已学表达数量

#### 4.14.2 场景掌握度计算
- 掌握度根据用户在该场景的学习次数、学习表达数量、AI对话练习次数、Shadowing跟读次数综合计算
- 掌握度以进度条形式展示在场景卡片上

#### 4.14.3 场景列表
- 系统预设10个常见学习场景：
  + Coffee Shop / 咖啡馆
  + Airport / 机场
  + Restaurant / 餐厅
  + Office / 办公室
  + Park / 公园
  + Supermarket / 超市
  + Subway / 地铁
  + Hospital / 医院
  + Library / 图书馆
  + Gym / 健身房

#### 4.14.4 等级与XP展示
- 顶部英雄区紧凑展示用户当前等级信息
- 包含等级徽章、等级名称（中英双语）、当前XP/升级所需XP、升级进度条、连续学习天数
- 等级体系保持不变：
  + Lv.1 英语新手 / English Beginner：所需总XP 0
  + Lv.2 初级学员 / Elementary Learner：所需总XP 100
  + Lv.3 进阶学员 / Advanced Learner：所需总XP 300
  + Lv.4 表达能手 / Expression Expert：所需总XP 600
  + Lv.5 场景达人 / Scene Master：所需总XP 1000
  + Lv.6 流利学者 / Fluent Scholar：所需总XP 1500
  + Lv.7 英语能手 / English Pro：所需总XP 2100
  + Lv.8 思维大师 / Thinking Master：所需总XP 2800
  + Lv.9 语言达人 / Language Expert：所需总XP 3600
  + Lv.10 英语领袖 / English Leader：所需总XP 5000

#### 4.14.5 经验值获取规则
- 拍照/描述场景并获得AI分析：+20 XP
- 完成一次AI场景对话练习：+30 XP
- 完成一次影子跟读（Shadowing）：+25 XP
- 翻译一张英文卡片：+5 XP
- 每日首次登录打卡：+10 XP
- 连续打卡奖励（连续7天）：+50 XP额外奖励

#### 4.14.6 数据存储
- XP数据存储在Supabase user_stats表，字段：user_id、total_xp、current_level、streak_days、last_checkin_date
- 场景解锁数据存储在scene_progress表，字段：user_id、scene_name、is_unlocked、mastery_level、learned_expressions_count

#### 4.14.7 升级逻辑
- 用户获得XP后，系统自动计算total_xp
- 根据total_xp判断用户当前等级
- 升级时给予成就反馈

#### 4.14.8 打卡与连续打卡
- 用户每日首次登录时，系统记录打卡日期
- 系统计算连续打卡天数（streak_days）
- 连续打卡7天时，额外奖励50 XP

### 4.15 学习时间线
- 首页学习时间线按时间分组展示学习记录（今天/昨天/本周）
- 每条记录显示场景缩略图和简短描述

  + 职场场景：会议、邮件、面试、商务谈判等

#### 4.16.2 场景节点状态
- 场景节点状态包括：
  + 已完成：用户完成该场景的对话练习
  + 进行中：用户已开始但未完成该场景的对话练习
  + 未解锁：用户尚未开始该场景的对话练习

#### 4.16.3 场景对话练习
- 用户进入场景详情页后，点击「开始练习」进入场景对话练习页面

- 用户扮演对应角色（如顾客、旅客、员工等）
- 进行角色扮演对话练习
- AI根据用户回复给出反馈和建议
- 记录对话轮次，更新场景进度

#### 4.16.4 学习进度记录
- 系统记录用户在每个场景完成的对话轮次
- 展示场景解锁/完成状态
- 数据存储在后端

1. 用户完成注册/登录
2. 用户在首页查看每日英语学习小贴士，显示当前日期、英文内容和中文解释

9. 用户从Shadowing跟读模式页面返回thinking-mode页面，分析结果和译文状态完整保留，不重新触发AI分析

11. 用户从单词详情页面返回thinking-mode页面，分析结果和译文状态完整保留，不重新触发AI分析
12. 用户收藏当前句子和场景

14. 用户进入AI英语地图页面，查看已练习场景和未练习场景，AI给出学习建议

17. 用户在英语世界地图页面查看场景地图区，查看10个学习场景节点（Coffee Shop / 咖啡馆、Airport / 机场、Restaurant / 餐厅、Office / 办公室、Park / 公园、Supermarket / 超市、Subway / 地铁、Hospital / 医院、Library / 图书馆、Gym / 健身房）
18. 用户在英语世界地图页面查看场景卡片详情，每个场景卡片显示场景名（中英双语）、场景图标或图片、掌握度进度条、已学表达数量
19. 用户点击已解锁场景卡片，进入对应场景的学习记录详情页面
20. 用户在首页学习时间线中查看历史学习记录，每条记录显示场景缩略图
21. 用户进入场景地图页面，查看地图视图，展示多个学习场景节点（日常生活场景和职场场景）
22. 用户在场景地图页面查看场景节点状态（已完成/进行中/未解锁）和对话轮次进度
23. 用户点击场景节点，进入场景详情页，查看场景介绍、常用词汇、对话目标
24. 用户在场景详情页点击「开始练习」，进入场景对话练习页面
