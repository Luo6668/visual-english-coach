# 英语日记 v2 · 本地验收

## 实际完成

- 中文自由写作，不依赖场景学习；自然表达 / 简单英语 / 润色表达。润色只要求改善措辞与衔接，提示词明确保留事实、否定与情绪，不追加经历。
- 生成结果为预览，必须确认保存。已有当天内容先显示阅读态，编辑后确认更新；源文变动后旧英文和朗读/保存失效，明确提示重新翻译。
- 完整月历、过去日期补写、未来日期禁用、有日记日期标记；日期与创建时间分别保留。历史列表显示日期和首句，选日期只读取对应内容。
- 草稿按账号 / 日期 / 每周范围保存在当前设备；三种版本候选按各自源文隔离；旧请求在输入变化、换日期或卸载后不能覆盖新状态。故障不清空中文。
- 英文可改、可朗读、可查看中文对照；旧日记没有中文不会伪造原文。编辑英文会清除不再可靠的自动拓展。
- 每篇最多 3 条实际正文中的学习表达，默认折叠，主动收藏才入表达本；可打开句子详解和既有词汇拓展。
- 可带入当天真实学习记录作为草稿文字，明确是练习内容。周记优先汇总已保存每日日记，无日记才明确使用真实学习记录；周记同样只生成预览，不自动替换原保存版本。
- 保留删除确认流程。个人工作台的日记编辑入口改为统一编辑器，并传入原日期/类型，避免另一套英文编辑造成中英文错配。

6. 屏蔽日记接口出现中文错误提示、中文原文仍在；解除屏蔽后重试成功。临时网络规则已清空。

## 数据兼容与运行

本地已执行 `pnpm mysql:migrate:diary` 所对应的非破坏性迁移，仅给 diaries 增加 4 个可空字段：source_text、writing_mode、source_kind、learning_expressions。旧英文正文、账号、XP 和学习数据不变。mysql:init 也会补齐这些字段；API 保留原 content 字段，旧个人卡/列表继续可读。

本地网关已重启并加载新接口，前端热更新可用。云端函数和 `00006_diary_writing_metadata.sql` 已提供，但本轮未部署云端。

## 不声称通过的范围

- AI 语义仍可能误译、遗漏或在周记衔接时误推先后；提示词约束不是事实真实性的数学保证。界面明确要求核对事实，本轮使用合成内容，不上传真实私人日记作测试。
- 草稿只在当前设备按账号隔离，不是跨设备同步。已保存双语正文落入既有数据库。
- 不提供并发多设备编辑合并；客户端重复点击有锁，同一日期顺序保存复用已有记录，数据库未增加唯一约束，也未删除历史重复日记。
- 原生手机、真人语音、Safari 实机、物理离线/存储配额故障未单独验收。本轮未实际点确认永久删除；保留了确认流程和账号范围，不能把未测操作表述为通过。
